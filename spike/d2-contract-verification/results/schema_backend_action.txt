                     Table "public.backend_action"
   Column   |           Type           | Collation | Nullable | Default 
------------+--------------------------+-----------+----------+---------
 id         | character varying(255)   |           | not null | 
 backend_id | character varying(255)   |           |          | 
 drone_id   | integer                  |           | not null | 
 action     | jsonb                    |           | not null | 
 created_at | timestamp with time zone |           | not null | now()
 acked_at   | timestamp with time zone |           |          | 
Indexes:
    "backend_action_pkey" PRIMARY KEY, btree (id)
    "idx_backend_action_backend" btree (backend_id)
    "idx_backend_action_created_at" btree (created_at)
    "idx_backend_action_pending" btree (drone_id, created_at) WHERE acked_at IS NULL
Foreign-key constraints:
    "backend_action_backend_id_fkey" FOREIGN KEY (backend_id) REFERENCES backend(id)
